TEXT-TO-SIGN ROOT CAUSES FOUND
1. app/routers/text_to_sign.py used the literal string "api_key":
   genai.Client(api_key="api_key")
   It has been corrected to:
   genai.Client(api_key=api_key)

2. reqs.txt did not contain google-genai. It has been added.

3. static/js/app.js and static/text_to_sign.html both declared:
   let textToSignVideos
   let currentVideoIndex
   The duplicate declarations can stop the newer inline Text-to-Sign script from loading.
   app.js now contains shared navigation code only.

4. The backend now prints why Gemini was skipped or failed.

HOW TO RUN
1. Copy .env.example to .env.
2. Put your own Gemini API key in .env.
3. Run: python -m pip install -r reqs.txt
4. Run: start_server.bat
5. Open: http://127.0.0.1:8000/docs
6. Test POST /api/text-to-sign.
7. Open the page and press Ctrl+F5.
